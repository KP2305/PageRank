# PageRank: Ranking Web Pages with Eigenvectors

DS5020 Final Project, Iteration 2
Team: Krisha Patel and Krishnananda Das

We model a small web as a directed graph, build the link matrix S and the
Google matrix G, and compute the PageRank vector by power iteration. The
report (`docs/`) contains the notation, definitions, assumptions, Q1-Q5, the
algorithm, the six-page example, the real-data exploration and the
simulation check.

## Folder guide
- `src/`     Python scripts (six-page simulation, real-data exploration)
- `data/`    dataset notes only; raw files are not committed
- `figures/` plots generated by the scripts
- `docs/`    compiled Overleaf PDF, project plan (Excel), SNAP summary output

## Setup

```bash
pip install numpy pandas matplotlib
```

## Data
We use the SNAP `web-Stanford` graph (281,903 pages, 2,312,497 hyperlinks).
Download `web-Stanford.txt.gz` from https://snap.stanford.edu/data/web-Stanford.html
and place it in `data/` (do not unzip it). The raw file is not committed to Git.

## How to run
Run both commands from the repository root.

**1. Six-page simulation** (needs only NumPy; no data download):
```bash
python src/pagerank_simulation.py
```
Builds A, S and G for the six-page web, runs power iteration (31 iterations at
tolerance 1e-10), compares it with the eigenvector of G and with a 100,000-step
random-surfer simulation (seed 0).

**2. SNAP real-data exploration** (needs `data/web-Stanford.txt.gz`):
```bash
python src/explore_snap.py --rule bfs
```
Writes `docs/snap_summary_bfs.txt` and `figures/degree_distribution_bfs.png`.
The subgraph is the 3,000 pages found by a breadth-first crawl starting at the
page with the most in-links. The script uses no random numbers, so every run
gives the same output. The other subgraph rules compared in the report can be
run with `--rule topdeg` and `--rule first`.
