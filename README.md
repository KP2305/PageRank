# PageRank: Ranking Web Pages with Eigenvectors

DS5020 Final Project (Iterations 2 and 3)
Team: Krisha Patel and Krishnananda Das

We model a small web as a directed graph, build the link matrix S and the
Google matrix G, and compute the PageRank vector by power iteration, then
check it against a Gaussian-elimination solution, an eigenvector and a library.

- **Iteration 2** (`docs/`): notation, definitions, assumptions, Q1-Q5, the
  algorithm, the six-page example, the SNAP data description and a simulation check.
- **Iteration 3** (`docs/`): a four-page worked example, the from-scratch
  implementation, the Iteration 3 math questions, the simulation test (error
  against the truth, a stress test), the real-data run with a SciPy comparison,
  the assumption checks and the verification table.

## Folder guide
- `src/`     Python scripts (see below)
- `data/`    dataset notes only; raw files are not committed
- `figures/` plots generated by the scripts
- `docs/`    compiled Overleaf PDFs, project plan (Excel), SNAP summary outputs

## Setup
```bash
pip install numpy pandas matplotlib scipy
```
Python 3.9 or newer is needed (`math.lcm`).

## Data
We use the SNAP `web-Stanford` graph (281,903 pages, 2,312,497 hyperlinks).
Download `web-Stanford.txt.gz` from https://snap.stanford.edu/data/web-Stanford.html
and place it in `data/` (do not unzip it). The raw file is not committed to Git.

## The code (Iteration 3)
| File | What it holds |
|---|---|
| `src/methods.py` | the from-scratch functions: `my_out_degrees`, `my_link_matrix`, `my_google_matrix`, `my_pagerank_step`, `my_power_iteration`, `my_gauss_solve`, `report` (NumPy only) |
| `src/simulate.py` | the six-page and four-page webs, the exact PageRank of the six-page web, and the random-surfer simulation |

`methods.py` and `simulate.py` are imported by the scripts below; they are not run directly
(`python src/simulate.py` prints a short demonstration).

## How to run
Run every command from the repository root.

**1. Four-page worked example** (step by step, exact fractions; needs no data):
```bash
python src/small_example.py
```

**2. Assumption checks on the simulated six-page graph** (eight checks, needs no data):
```bash
python src/check_assumptions_sim.py
```

**3. Simulation test** (error against sample size, library comparison, alpha = 0.99 stress test):
```bash
python src/check_simulation.py
```

**4. Real data** (3,000-page web-Stanford subgraph and the SciPy comparison; needs `data/web-Stanford.txt.gz`):
```bash
python src/run_real.py
```

## Iteration 2 scripts
```bash
python src/pagerank_simulation.py      # six-page simulation (power iteration, eigenvector, random surfer)
python src/explore_snap.py --rule bfs  # SNAP exploration; also --rule topdeg and --rule first
```
`explore_snap.py` writes `docs/snap_summary_<rule>.txt` and
`figures/degree_distribution_<rule>.png`. The subgraph (3,000 pages from a
breadth-first crawl starting at the page with the most in-links) uses no random
numbers, so every run gives the same output.

## Reproducibility
Every script that uses randomness fixes the seed with `np.random.default_rng(0)`,
so every member gets the same numbers.
